# 🛡️ ssl-expiry-guard

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Zero Dependency](https://img.shields.io/badge/Dependencies-Zero-brightgreen.svg)](https://github.com/MobileConduit)

Proactive SSL certificate expiration inspector built to eliminate unplanned outages. Queries TLS handshakes across hundreds of domain names in seconds and highlights certificates entering expiration thresholds.

```bash
python expiry_guard.py --domains enterprise.com cloud.enterprise.com streaming.net
```
